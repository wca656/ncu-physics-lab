## 二、仓库用途

- 按周归档实验报告（文字、公式、图像）；
- 保存实验原始数据与处理过程，保证结果**可复现**；
- 沉淀 Python / 数据分析脚本，训练"物理 + 计算"的交叉能力；
- 通过 Git 提交历史，直观展示个人学习成长轨迹。

## 五、如何使用本仓库

```bash
# 1. 克隆到本地
git clone <仓库地址>

# 2. 进入某一周的实验目录
cd week03_gravity_simple_pendulum

# 3. 完成实验后，提交你的成果
git add .
git commit -m "week03: 完成单摆测重力加速度实验报告"
git push
```
