## 实验目的
- 用数值方法（如四阶龙格-库塔）求解单摆运动方程；
- 对比小角度近似解与大角度真实解的差异；
- 可视化摆角、角速度随时间的演化。

## 实验原理
单摆运动方程：

$$\frac{d^2\theta}{dt^2} + \frac{g}{L}\sin\theta = 0$$

小角度近似 $\sin\theta \approx \theta$ 时，周期 $T \approx 2\pi\sqrt{L/g}$。
